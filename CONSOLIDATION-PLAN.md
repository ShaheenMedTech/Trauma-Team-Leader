# Trauma Team Leader — Consolidation Plan

## Purpose

This document defines the execution plan for consolidating the existing
manuscript into the approved 30-chapter architecture.

No substantive content is deleted at this stage.

Each existing section will be classified as:

- KEEP — retain in its current canonical chapter
- MERGE — merge with another section covering the same concept
- MOVE — relocate to a more appropriate chapter
- CROSS-REFERENCE — retain the concept but avoid repeating the full explanation
- REWRITE — preserve the substance while improving structure and reducing duplication
- CREATE — new connective material required by the final architecture

# Execution Rules

1. Do not delete source files before consolidation is verified.
2. Do not renumber manuscript files until the architecture is stable.
3. Do not remove substantive clinical content.
4. Do not duplicate complete explanations across chapters.
5. Establish one canonical location for every major leadership concept.
6. Use cross-references where repetition would otherwise occur.
7. Preserve clinically useful examples.
8. Preserve case-based reasoning where it adds application value.
9. After each consolidation group:
   - run structural checks,
   - inspect the diff,
   - commit the change.
10. The original `main` branch remains untouched until the entire restructuring
    has been reviewed.
